We design the optimal-rate, capacity-approaching irregular LDPC code ensemble over the binary erasure channel using a practical semidefinite programming approach, without relying on relaxation or approximate solutions used in prior work. This resolved the previously open problem of the optimal rate for LDPC codes on the BEC.
